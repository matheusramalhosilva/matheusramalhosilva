# Matheus Ramalho

### E ai, blz? :v: :leaves:
Me chamo Matheus Ramalho, mas pode me chamar de Mat.

Sou um engenheiro de software frontend, graduado em Sistemas de Informação com 8+ anos de experiência no desenvolvimento e designer. Ao longo da minha trajetória permaneço estudando e evoluindo na carreira e como profissional, evoluindo na stack javascript. 

Tenho o objetivo de me tornar um engenheiro especialista na stack javascript, abrangendo não só a web, mas tambémno mobile e no backend, me tornando um especialista full stack.

Minha espertise se extende entre Javascript, Typescript, React, React Native, Next, Tailwind, entre outras. Já atuei em projetos de diversos seguimentos, como um sistema de prevenção a lavagem de dinheiro, sistema que gere toda a vida do estudante de ensino superior e sistemas de armazenamento e consulta de documentos. Também desenvolvo um projeto pessoal mobile com as tecnologias React Native, Expo, Tailwind e Tanstack Query, para gerencia de alunos com trainos e alimentação.

O desenvolvimento é uma verdadeira paixão para mim. Acredito no poder do código para transformar ideias em realidades funcionais e belas. É gratificante saber que meu trabalho pode fazer a diferença, proporcionando experiências de qualidade para os usuários.

Vamos construir algo incrível juntos!
